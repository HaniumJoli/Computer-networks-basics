# Computer Networks Basics

Simple practice of basic computer network configuration using Cisco Packet Tracer. Each file is a small lab I built while learning. Open the `.pkt` files in Cisco Packet Tracer to follow along or try them yourself.

## Practice labs

| Topic | Files |
|---|---|
| Basics | `Simple_Switch.pkt`, `Simple_Router.pkt`, `Switch_Router.pkt`, `Switch_Router_mixed.pkt` |
| Static routing | `Static_Routing.pkt` |
| Dynamic routing | `RIP.pkt`, `OSPF.pkt` |
| VLANs | `VLAN.pkt` |
| Network services | `DHCP.pkt`, `DNS.pkt`, `NAT.pkt` |
| Security | `ACL.pkt`, `SSH.pkt` |
| Small network | `Small_Organization.pkt` |
| Combined practice | [Secure_Multi_Department_Network](Secure_Multi_Department_Network/README.md) |

## How to use

1. Install Cisco Packet Tracer.
2. Download a `.pkt` file from this repository.
3. Open it in Packet Tracer and explore the devices (CLI tab on routers and switches, Desktop tab on PCs and servers).

## Topics practised

IP addressing, switching, static routing, RIP, OSPF, VLANs and trunking, DHCP, DNS, NAT, access control lists, SSH.
